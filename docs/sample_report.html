How to read this

  • PadLab only reads the controller while you play. It does not know what you meant to press, so each check looks for patterns that a hand does not make, or uses moments when you did not touch a stick.
  • OK / Watch / Problem limits are PadLab defaults (judgement calls), not industry standards. You can change them in THRESHOLDS in analysis.py.
  • Timing is limited by the logger loop (about 1 ms) and by Windows. PadLab can't measure true input latency. That needs hardware.
  • Steam Input, DS4Windows and similar tools can change what PadLab sees. Turn them off for a clean test.
  • Compare controllers only with the same player, game and connection.
